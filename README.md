# Car Service Tg Bot

Телеграм-бот для автосервиса, который уведомляет клиентов о необходимости посетить СТО и отметиться для сохранения гарантии на аккумуляторы. В комплекте админ-панель для управления уведомлениями и контентом по обслуживанию автомобилей.

## Начало работы

### Установка

```bash
git clone https://github.com/bx6xb/car-service-tg-bot
cd car-service-tg-bot
pnpm i
```

### Настройка

Создайте и заполните файл `.env`:

```env
SUPABASE_URL=https://...
SUPABASE_KEY=123abc...
BOT_TOKEN=token
ADMIN_IDS=123,456,789
API_URL=https://...
```

## Скрипты для работы с проектом

- `pnpm dev` — запуск проекта в режиме разработки
- `pnpm build` — сборка проекта в минифицированный банд
- `pnpm start` — запуск собранного бандла
- `pnpm format` — форматирование кода с помощью Prettier
- `pnpm lint` — проверка кода на ошибки с помощью ESLint

## Стек технологий

### Основные библиотеки и инструменты

- **Node.js** — среда выполнения JavaScript/TypeScript
- **TypeScript** — язык программирования с поддержкой статической типизации
- **Telegraf** — фреймворк для создания Telegram-ботов
- **supabase** — база данных
- **cron** — планировщик периодических задач
- **esbuild** — высокоскоростной сборщик и минификатор кода
- **dotenv** — загрузка переменных окружения из `.env` файлов

### Вспомогательные инструменты

- **pnpm** — быстрый и экономичный менеджер пакетов
- **ts-node** — выполнение TypeScript-файлов без предварительной компиляции
- **eslint** — линтер для поддержания качества кода
- **prettier** — автоматическое форматирование кода
