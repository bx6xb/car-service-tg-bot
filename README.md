# Car Service Tg Bot

Телеграм-бот для автосервиса, который уведомляет клиентов о необходимости посетить СТО и отметиться для сохранения гарантии на аккумуляторы. В комплекте админ-панель для управления уведомлениями и контентом по обслуживанию автомобилей.

## Начало работы

### Установка

```bash
git clone https://github.com/bx6xb/car-service-tg-bot
cd car-service-tg-bot
pnpm i
```

### Настройка

Создайте файл `.env` и добавьте токен:

```env
TOKEN=your_telegram_bot_token
```

## Скрипты для работы с проектом

- `pnpm dev` — запуск проекта в режиме разработки

- `pnpm build` — сборка проекта в минифицированный банд
- `pnpm start` — запуск собранного бандла
- `pnpm format` — форматирование кода с помощью Prettier
- `pnpm lint` — проверка кода на ошибки с помощью ESLint

## Стек

### Основные библиотеки и инструменты

- Node.js — платформа для запуска кода на JavaScript/TypeScript
- TypeScript — язык программирования с типами
- Telegraf — фреймворк для создания Telegram-ботов
- esbuild — быстрый сборщик и минификатор кода
- dotenv — загрузка переменных окружения из .env

### Другие библиотеки и инструменты

- pnpm — менеджер пакетов
- ts-node — запуск TypeScript напрямую без компиляции
- eslint — статический анализатор кода
- prettier — форматирование кода
